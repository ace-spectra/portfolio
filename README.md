## ✦ About

**Ace Spectra** is a personal developer portfolio focused on showcasing projects, skills and experience through a clean, minimal interface.


## 🛠️ Built With

| Technology           | Usage                          |
| -------------------- | ------------------------------ |
| **HTML5**            | Page structure and content     |
| **CSS3**             | Styling, layout and animations |
| **JavaScript**       | Interactions and animations    |
| **Google Fonts**     | Manrope typography             |
| **Cloudflare Pages** | Deployment                     |

## 🎨 Design

The portfolio follows a deliberately minimal visual language:

* Near-black background
* High-contrast white typography
* Large display typography
* Subtle borders and translucent surfaces
* Rounded navigation
* Geometric background elements
* Smooth scrolling
* Interactive cursor effects

The goal is to keep the interface visually interesting without overwhelming the content.
